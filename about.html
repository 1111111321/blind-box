About

How this site came together

A blind-box site made in a weekend: four pages, one stylesheet, a little JavaScript.

Why a blind box

The fun of a blind box is not the thing inside, it is the few seconds before you open it. This site tries to keep that pause: twelve boxes, one click, one small thing.

How it is built

  • Four pages, each a separate HTML file. The navigation is made of real links, not a menu assembled by script.
  • All styling lives in one style.css; colour, spacing and type are defined once as variables.
  • Pieces, odds and the draw itself live in app.js. The odds table is generated from the same data the draw uses.
  • Progress is stored in the browser's localStorage. There is no account and nothing is uploaded.

What was left out

The first version was loud: gradients, glow, confetti. Those buried the content and were heavy on a phone. Now there is one accent colour, and only two pieces of motion — a small nudge when a box opens, and a fade for the result.

Accessibility

  • Boxes are real <button> elements, so they work from the keyboard; the result is announced through aria-live.
  • The result dialog closes with Esc, and focus returns to the box that was opened.
  • With reduced motion turned on, the animations are switched off; dark mode follows the system.
