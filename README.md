# 星屿盲盒

一个纯前端的小盲盒站：点开盒子，抽走今天的十二分之一。

没有框架、没有构建、没有服务器、没有账号。所有进度存在浏览器本地的 `localStorage` 里。

## 页面

| 文件 | 内容 |
|---|---|
| `index.html` | 抽盒：12 个盒子、开盒动画、结果浮层、保底进度 |
| `collection.html` | 收藏册：12 个格子，抽到的亮起来，可清空记录 |
| `odds.html` | 概率与玩法：每一档的概率表、单件概率、规则说明 |

## 结构

```
blind-box/
├── index.html
├── collection.html
├── odds.html
├── style.css        一个样式表管三个页面
├── app.js           数据 + 抽盒逻辑 + 三个页面的渲染
└── favicon.svg
```

## 怎么跑

直接双击 `index.html` 就能玩 —— 没有 `fetch`，也就不需要本地服务器。

想用服务器预览也行：在这个文件夹里执行 `python -m http.server 8000`，再打开 <http://localhost:8000>。

## 逻辑在哪

- **物品与概率**：`app.js` 顶部的 `ITEMS` 和 `RARITY`。每档的 `weight` 就是概率权重，改完 `odds.html` 的表格会自动跟着变（表格是算出来的，不是手写的）。
- **抽盒**：先按权重摇稀有度，再在该档里等概率取一件。
- **保底**：`PITY = 10`。连续 10 抽没有史诗及以上时，第 10 抽必出。
- **一箱 12 个**：开过的盒子在本次不会重复出现，整箱开完可「再装一箱」；收藏记录继续累计。
- **存档**：`localStorage` 键名 `xingyu.box.v1`，存抽数、每件数量、保底计数和最近记录。

## 其它

- 深色模式跟随系统（`prefers-color-scheme`）。
- 键盘可点盒子，`Esc` 关闭结果浮层，结果会通过 `aria-live` 播报。
- 开了系统「减少动态效果」时，动画会基本关掉。
